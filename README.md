# md2docx

Універсальний високошвидкісний автономний конвертер Markdown у формати **DOCX** (Microsoft Word) та **PDF** із підтримкою підстановки змінних (Jinja2 + YAML), векторних математичних формул (LaTeX → OMML), графічних діаграм Mermaid та інформаційних блоків у стилі macOS. Повністю автономний — не потребує встановлення LibreOffice, Microsoft Office або Python для роботи бінарника.

Доступний у двох реалізаціях:
1. **Rust CLI (рекомендовано):** ультрашвидкий нативний бінарник (~2-3 мс на DOCX, ~130 мс на PDF, ~8-10 МБ RAM).
2. **Python скрипт (`md2docx.py`):** автономний single-file скрипт без компіляції.

## Ключові можливості

* **Екстремальна продуктивність (Rust):** холодний старт 1–2 мс, обробка великих документів за мілісекунди.
* **Вбудований рушій верстки Typst для PDF:** пряма компіляція Markdown у векторний PDF друкарської якості за 50–90 мс. Не потребує жодних сторонніх офісних пакетів (LibreOffice, MS Office, wkhtmltopdf чи Python). Включає вбудований офіційний варіативний шрифт Google Roboto Flex, забезпечує адаптивне масштабування графіків на 100% ширини сторінки, стилізовані GFM-таблиці з чергуванням фону рядків, плавне керування розривами сторінок, захист від «висячих» рядків (widows/orphans), витончені колонтитули та векторні піктограми статусу.
* **Діаграми Mermaid:** автоматичний рендеринг блоків ```` ```mermaid ```` у високоякісні зображення з масштабуванням під ширину сторінки (використовує Kroki POST API з локальним кешуванням).
* **Callout-блоки (macOS SF Style):** підтримка GitHub Alerts (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`) з відповідними кольоровими лінійками, фоном та системними піктограмами.
* **Нативні формули Word:** трансляція LaTeX-формул у редаговані об'єкти Word (OMML).
* **Контейнеризація коду:** табличні контейнери $1 \times 1$ з бейджем мови, що усувають білі просвіти між рядками.
* **Шаблонізація:** підтримка синтаксису Jinja2 (`minijinja` у Rust), глибоке злиття YAML front matter та зовнішніх data-файлів, перевизначення через `--var`.

## Бенчмарки продуктивності (Порівняння Rust vs Python)

| Метрика | **Rust CLI** 🦀 | **Python** 🐍 | Прискорення |
| :--- | :--- | :--- | :---: |
| **Час конвертації (sample.md)** | **2.0 мс** | **610 мс** | **у 305 разів швидше** |
| **Час конвертації (8-стор. звіт)** | **2.9 мс** | **950 мс** | **у 320 разів швидше** |
| **Пікове споживання RAM (RSS)** | **8.1 МБ** | **75.3 МБ** | **у 9.2 раза менше** |
| **Розмір релізного бінарника** | **11.4 МБ** (UPX LZMA) / 39 МБ (raw) | потрібен Python + pip | автономно (включно з Typst та шрифтом Roboto Flex) |

## Встановлення та збірка

### 1. Автоматична збірка з UPX-компресією (рекомендовано)
```bash
git clone https://github.com/andysu/md2docx.git
cd md2docx
./build.sh
# Готовий оптимізований бінарник: ./target/release/md2docx (~11.4 МБ)
```

Або стандартна збірка через Cargo без UPX:
```bash
cargo build --release
# Готовий бінарник: ./target/release/md2docx (~36 МБ)
```

### 2. Python скрипт
```bash
pip install -r requirements.txt
python3 md2docx.py --help
```

## Використання

```bash
# Довідка з прикладами (також показується при запуску без аргументів)
md2docx --help

# Конвертація документа у DOCX
md2docx document.md -o output.docx

# Нативна конвертація безпосередньо у PDF (без офісних пакетів)
md2docx document.md -o output.pdf

# Одночасна генерація DOCX та PDF
md2docx document.md -o output.docx --pdf

# Детальний покроковий вивід кожного етапу (verbose)
md2docx document.md -o output.pdf -v

# З підстановкою даних із YAML
md2docx template.md -o output.docx --data data.yaml

# З перевизначенням окремих змінних
md2docx template.md -o output.docx --data data.yaml --var client.name="ТОВ Світанок"

# Діагностика без запису файлу
md2docx document.md --check
```
