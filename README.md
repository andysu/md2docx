# md2docx

Універсальний високошвидкісний автономний конвертер Markdown у формат DOCX (Microsoft Word) із підтримкою підстановки змінних (Jinja2 + YAML), векторних математичних формул (LaTeX → OMML), графічних діаграм Mermaid та інформаційних блоків у стилі macOS.

Доступний у двох реалізаціях:
1. **Rust CLI (рекомендовано):** ультрашвидкий нативний бінарник (~2-3 мс на документ, ~8-10 МБ RAM).
2. **Python скрипт (`md2docx.py`):** автономний single-file скрипт без компіляції.

## Ключові можливості

* **Екстремальна продуктивність (Rust):** холодний старт 1–2 мс, обробка великих документів за мілісекунди.
* **Діаграми Mermaid:** автоматичний рендеринг блоків ```` ```mermaid ```` у високоякісні зображення з масштабуванням під ширину сторінки (використовує Kroki POST API з локальним кешуванням).
* **Callout-блоки (macOS SF Style):** підтримка GitHub Alerts (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`) з відповідними кольоровими лінійками, фоном та системними піктограмами.
* **Нативні формули Word:** трансляція LaTeX-формул у редаговані об'єкти Word (OMML).
* **Контейнеризація коду:** табличні контейнери $1 \times 1$ з бейджем мови, що усувають білі просвіти між рядками.
* **Шаблонізація:** підтримка синтаксису Jinja2 (`minijinja` у Rust), глибоке злиття YAML front matter та зовнішніх data-файлів, перевизначення через `--var`.

## Бенчмарки продуктивності (Порівняння Rust vs Python)

| Метрика | **Rust CLI** 🦀 | **Python** 🐍 | Прискорення |
| :--- | :--- | :--- | :---: |
| **Час конвертації (sample.md)** | **2.0 мс** | **610 мс** | **у 305 разів швидше** |
| **Час конвертації (8-стор. звіт)** | **2.9 мс** | **950 мс** | **у 320 разів швидше** |
| **Пікове споживання RAM (RSS)** | **8.1 МБ** | **75.3 МБ** | **у 9.2 раза менше** |
| **Розмір релізного бінарника** | **7.2 МБ** (standalone) | потрібен Python + pip | автономно |

## Встановлення та збірка

### 1. Rust CLI (бінарник)
```bash
git clone https://github.com/andysu/md2docx.git
cd md2docx
cargo build --release
# Готовий бінарник: ./target/release/md2docx
```

### 2. Python скрипт
```bash
pip install -r requirements.txt
python3 md2docx.py --help
```

## Використання

```bash
# Конвертація документа
md2docx document.md -o output.docx

# З підстановкою даних із YAML
md2docx template.md -o output.docx --data data.yaml

# З перевизначенням окремих змінних
md2docx template.md -o output.docx --data data.yaml --var client.name="ТОВ Світанок"

# Діагностика без запису файлу
md2docx document.md --check
```
